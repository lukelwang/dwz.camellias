## 操作问题与修复

1. **切换照片或收藏后丢失键盘焦点。** 重新渲染后恢复到对应操作；关闭相册或全屏视图时返回原入口。移除最后一个收藏后，焦点转到返回全部品种的按钮。
2. **导入下一张照片时打断说明输入。** 待上传照片逐条增加和移除，不再重建已有输入框；中文输入、光标和焦点可以保留。
3. **加载、错误、空收藏和无搜索结果共用模糊提示。** 分别提供对应文案；加载失败时可以直接在收藏区域重试，无需滚回页顶。
4. **冲突重载可能覆盖其他会话的修改。** 品种、照片和站点设置表单只提交实际修改的字段；重载时保留修改过的草稿，更新未修改的字段。照片原有 EXIF 日期来源和时区也会保留。
5. **公开相册提示访客手工填写日期。** 缺少日期时只显示 Capture date unknown。
6. **计数单复数不自然。** 修正 1 cultivar、1 photo 等计数。

- 独立模拟 GitHub 后端完成 119 次 API 交互，验证多选上传、EXIF、失败保留草稿、从品种编辑页追加照片，以及照片/品种/设置的并发冲突恢复。
