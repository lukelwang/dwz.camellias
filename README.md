# DWZ Camellias

A personal camellia photo gallery.

The interactive administration prototype lives on the `codex/camellia-admin-prototype` branch. Its preview is hosted at https://lukelwang.github.io/dwz.camellias/ . It uses a public demo token and in-memory sample data; no production authentication or photo-repository integration is active.

Planned photo repository name: `dwz.camellias.photo`.
